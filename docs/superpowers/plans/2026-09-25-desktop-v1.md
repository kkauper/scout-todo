# Desktop v1 (DT-2 … DT-8): tray timer, window lifecycle, links, offline launcher, icon, CI release

Builds on the spike (`desktop/src-tauri`, see `docs/DESKTOP-SPIKE.md`). macOS only (Apple Silicon, aarch64). No Apple signing (ad-hoc `-`), no updater yet.

Toolchain: `source "$HOME/.cargo/env"` before cargo commands; Tauri CLI via `cargo tauri` (2.11.x). Web app conventions as in the rest of the repo (no semicolons, single quotes, 2-space indent).

End result:
- App icon = `public/favicon.svg` (round, dark bg, yellow O+check), with macOS padding.
- Menu bar tray: monochrome template icon + elapsed `h:mm` title while a timer runs; menu with status line, Open Scout, Stop timer, Quit Scout.
- Window close hides (app keeps running in tray/dock); ⌘Q / Quit exits; Dock click reopens; only one instance.
- Window size/position remembered.
- Links to other sites open in the default browser.
- Starts on a local launcher page that shows an offline message + retry when the site can't be reached.
- Web app tells the shell about the running timer; tray "Stop timer" stops it through the web app.
- GitHub Actions builds the dmg on a `desktop-v*` tag and attaches it to a draft release.

## Step 3 — Launcher / offline page (DT-4)

Replace `desktop/offline/index.html` with a self-contained page (inline CSS + inline script, no external resources):
- Reads `target` from `location.search` (`new URLSearchParams(location.search).get('target')`); if missing use `https://scout.kauper.co`.
- `async function tryOpen()`: `await fetch(target + '/favicon.svg', { mode: 'no-cors', cache: 'no-store' })`; on success `location.replace(target)`; on failure show the offline state.
- Initial state: centered text "Opening Scout…". Offline state: heading "Scout can't be reached", text "Check your internet connection. Retrying automatically…", and a `<button type="button">Retry now</button>`. Auto-retry every 10 s while offline.
- Colors: background `#1c1c1c`, text `#f5f5f5`, button background `#ddfe5a` with text `#1c1c1c`; system font; `<html lang="en">`; respects `prefers-color-scheme` is not needed (always dark, matches icon).
- Status text in an element with `role="status"` so screen readers hear state changes.

## Step 4 — Rust (DT-2, DT-3, DT-5, DT-6, DT-7)

Split into modules under `desktop/src-tauri/src/`:

### `nav.rs`
- `pub const DEFAULT_URL: &str = "https://scout.kauper.co";`
- `pub fn scout_url() -> &'static str` → `option_env!("SCOUT_URL").unwrap_or(DEFAULT_URL)` (compile-time override for local dev: `SCOUT_URL=http://localhost:3000 cargo tauri dev`).
- `pub fn is_internal(url: &url::Url, scout: &url::Url) -> bool` → true if `url.scheme()` is `tauri` or `about`, or host is `tauri.localhost`, or `url.origin() == scout.origin()`. Everything else false.
- Unit tests (`#[cfg(test)]`): scout origin with path → true; `tauri://localhost/index.html` → true; `http://tauri.localhost/index.html` → true; `about:blank` → true; `https://github.com/x` → false; `https://scout.kauper.co.evil.com` → false; `http://scout.kauper.co` (wrong scheme) → false.

### `timer.rs`
- `#[derive(serde::Deserialize, Clone)] #[serde(rename_all = "camelCase")] pub struct TimerPayload { pub task_title: String, pub started_at_ms: i64 }`
- `#[derive(Default)] pub struct TimerState(pub std::sync::Mutex<Option<TimerPayload>>);`
- `pub fn format_elapsed(started_at_ms: i64, now_ms: i64) -> String` → `h:mm` (e.g. `0:05`, `1:42`, `12:03`); negative elapsed → `0:00`.
- `pub fn truncate_title(title: &str, max: usize) -> String` → char-safe truncation, appends `…` when cut (max 40 used by tray).
- `#[tauri::command] pub fn timer_changed(app: tauri::AppHandle, state: tauri::State<TimerState>, timer: Option<TimerPayload>)` → store in the mutex, then `crate::tray::refresh(&app)`.
- Unit tests for `format_elapsed` (0 s, 59 s → `0:00`, 5 min, 61 min → `1:01`, 12 h 3 min, negative) and `truncate_title` (short unchanged, long cut with `…`, multi-byte chars like `ä`/emoji don't panic).

### `tray.rs`
- `pub struct TrayItems { pub status: MenuItem<Wry>, pub stop: MenuItem<Wry> }` stored via `app.manage(...)`.
- `pub fn create(app: &AppHandle) -> tauri::Result<()>`:
  - Menu items (ids in quotes): status `"status"` (disabled, text "No timer running"), `"open"` "Open Scout", `"stop"` "Stop timer" (disabled initially), separator, `"quit"` "Quit Scout".
  - `TrayIconBuilder::with_id("main")`, icon `Image::from_bytes(include_bytes!("../icons/tray.png"))?`, `.icon_as_template(true)`, `.tooltip("Scout")`, `.menu(&menu)`, `.show_menu_on_left_click(true)`.
  - Menu event handler: `open` → `crate::show_main(app)`; `stop` → `app.emit_to("main", "tray-stop-timer", ())`; `quit` → `app.exit(0)`.
- `pub fn refresh(app: &AppHandle)`: read `TimerState`; running → tray title `Some(format_elapsed(..))`, status text `"Tracking: " + truncate_title(title, 40)`, stop enabled; idle → title `None`, status "No timer running", stop disabled. Ignore errors (log with `eprintln!`).
- `pub fn start_ticker(app: AppHandle)`: `std::thread::spawn` loop: sleep 15 s, `refresh(&app)`.

### `lib.rs`
- `mod nav; mod timer; mod tray;`
- `pub fn show_main(app: &AppHandle)`: get window `"main"`; `show()`, `unminimize()`, `set_focus()`; ignore errors.
- `run()`:
  ```rust
  tauri::Builder::default()
      .plugin(tauri_plugin_single_instance::init(|app, _args, _cwd| show_main(app)))  // must be first
      .plugin(tauri_plugin_window_state::Builder::default().build())
      .plugin(tauri_plugin_opener::init())
      .manage(timer::TimerState::default())
      .invoke_handler(tauri::generate_handler![timer::timer_changed])
      .setup(|app| { /* see below */ Ok(()) })
      .on_window_event(|window, event| { /* CloseRequested on "main": api.prevent_close(); window.hide() */ })
      .build(tauri::generate_context!())
      .expect("error while building tauri application")
      .run(|app, event| { /* macOS: RunEvent::Reopen { has_visible_windows: false, .. } → show_main(app) */ });
  ```
- `setup`:
  1. `#[cfg(debug_assertions)] app.add_capability(include_str!("../dev-capabilities/localhost.json"))?;`
  2. `let scout = url::Url::parse(nav::scout_url())?;`
  3. Launcher URL: `WebviewUrl::App(format!("index.html?target={}", urlencoding of scout_url).into())` — encode with `url::form_urlencoded::byte_serialize`.
  4. `WebviewWindowBuilder::new(app, "main", launcher)` with `.title("Scout")`, `.inner_size(1280.0, 800.0)`, `.min_inner_size(900.0, 600.0)`, `.background_throttling(tauri::utils::config::BackgroundThrottlingPolicy::Disabled)`, and:
     - `.on_navigation(move |url| if nav::is_internal(url, &scout) { true } else { open in browser via tauri_plugin_opener (`app_handle.opener().open_url(url.as_str(), None::<&str>)`); false })` — clone an `AppHandle` into the closure.
     - `.on_new_window(...)`: for `target=_blank` / `window.open` → if the Tauri version provides it, open the URL in the browser via opener and deny the new window. If `on_new_window` doesn't exist in the resolved Tauri version, skip it and report as deviation.
     - `.build()?`
  5. `tray::create(app.handle())?; tray::refresh(app.handle()); tray::start_ticker(app.handle().clone());`
- Remove the `ping` command.
- Exact type/method names above are from Tauri 2.x; if one differs in the resolved version, use the equivalent API with the same behavior and list it under deviations.

## Step 5 — Web app bridge (DT-6)

1. `pnpm add @tauri-apps/api@^2` (root package).
2. New `app/plugins/desktop.client.ts`:
   ```ts
   import { watch } from 'vue'
   import { useBoardStore } from '../stores/board'

   // Only active inside the Scout desktop app (Tauri). No-op in browsers.
   export default defineNuxtPlugin(async () => {
     if (!('__TAURI_INTERNALS__' in window)) return
     const [{ invoke }, { listen }] = await Promise.all([import('@tauri-apps/api/core'), import('@tauri-apps/api/event')])
     const store = useBoardStore()
     ...
   })
   ```
   - A `computed` string key: `null` when `store.runningTimer` is null, otherwise `JSON.stringify({ taskTitle, startedAtMs })` where `taskTitle` = title of the task with `id === runningTimer.taskId` (fallback `'Timer'`), `startedAtMs = Date.parse(runningTimer.startedAt)`.
   - `watch(key, (k) => { invoke('timer_changed', { timer: k ? JSON.parse(k) : null }).catch(() => {}) }, { immediate: true })`.
   - `await listen('tray-stop-timer', () => { if (store.runningTimer) store.stopTimer() })`.
   - Wrap the listen in try/catch (ignore errors) so a permission problem never breaks the web app.
3. The dynamic imports must stay inside the guard so browsers never load the Tauri module eagerly; check the production build doesn't fail (`pnpm build` is not required; `pnpm typecheck` is).

## Step 6 — CI release (DT-8)

New `.github/workflows/desktop-release.yml`:
```yaml
name: Desktop release

on:
  push:
    tags: ['desktop-v*']

permissions:
  contents: write

jobs:
  macos:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
        with:
          workspaces: 'desktop/src-tauri -> target.nosync'
      - name: Check version matches tag
        run: |
          conf=$(jq -r .version desktop/src-tauri/tauri.conf.json)
          tag="${GITHUB_REF_NAME#desktop-v}"
          if [ "$conf" != "$tag" ]; then echo "tauri.conf.json version $conf != tag $tag"; exit 1; fi
      - name: Build dmg
        working-directory: desktop/src-tauri
        run: npx --yes @tauri-apps/cli@2 build --bundles dmg
      - name: Create draft release
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          gh release create "$GITHUB_REF_NAME" desktop/src-tauri/target.nosync/release/bundle/dmg/*.dmg \
            --draft \
            --title "Scout Desktop ${GITHUB_REF_NAME#desktop-v}" \
            --notes "macOS (Apple Silicon). Unsigned: after installing, open System Settings → Privacy & Security → Open Anyway."
```
Do not push tags or run the workflow.
